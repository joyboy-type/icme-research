# 局部残差检测：开发集分组验证

本轮只使用 DiffSpot 的240对开发原图，未使用旧355确认样本、历史155样本或72个官方无改动对照。分组是原始截图/近重复代理，不能称为网站隔离。Word任务书保持冻结。

固定整页相位校正后，比较整页残差面积、32像素局部残差最大值、最大连通区域和固定ExtraTrees局部特征分类器。所有输入均来自截图；不使用DOM、真值区域或标签作为特征。外层三折留组测试，内层三折折外负例校准学习方法阈值；JPEG90/98不参与拟合与校准。

学习方法在位置、文字、圆角三个开发类别上的干净检出率均为100%；这仍是开发分布内信号。局部最大残差已经解释了相当部分改善，尚无新方法的独立贡献证据。最终全量模型与折外模型的概率尺度可能不同，校准目标5%不构成总体误报保证。下一轮使用不同来源框架家族的受控探针检验迁移。

`outputs/summary.json`保留完整结果；`outputs/public_decisions.json`是保留所有逐样本0/1决定的紧凑表，可重算各条件和各类检出/误报率。完整分数、特征、模型、图片和日志仅在本地。

曾发生分类别统计掩码错误，已只修正统计输出并从原预测重算；原统计、原代码及原设计锁均保留于`attempts/`和`design_lock.json`。总分、阈值、预测、模型未改变，详见`outputs/reporting_fix.json`。独立重算108个统计单元，5项相关测试通过。
