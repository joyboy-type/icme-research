# 按来源框架家族隔离的受控网页探针确认

本轮已完成冻结确认。局部特征改善了干净变更检出，但压缩误报仍未达到5%的目标；旧开发方法直接迁移时误报严重。尚未形成可用的稳健检测器，也未建立论文方法贡献。

12个固定版本的上游HTML/CSS框架家族，保留现有页面内容，清理外部资源后离线渲染。38个上游文件按Git blob核验，2个版本化CDN样式按冻结SHA256核验；原始来源、许可证、截图仅保留本地。数据是**清理后的框架页面受控CSS探针，不是真实生产网站或独立人工页面基准**。

|划分|家族数|有效变更对|唯一基准视图|
|---|---:|---:|---:|
|训练|4|292|10|

家族划分在评分前固定。32个基准视图逐对验证恢复到相同像素；跨划分无完全相同像素截图。每个无改动基准/扰动条件只计一次，未按变更数量重复。滚动视图和CSS强度相关，统计重采样单位是来源框架家族。

训练集中justify为0例、position为5例；确认集中分别2例和5例。因此固定13类主指标不能解释为13类均受训的闭集泛化。辅助fixed12是在全部确认样本上对除justify以外12个标签取宏平均；未删除justify样本，其错误预测仍可能贡献其他类的假阳性。

## 冻结分类结果

只在四个训练家族的干净截图拟合固定ExtraTrees，全部方法共享像素差确定的裁剪；特征提取不使用DOM或标注区域，标签仅作监督目标。DINO使用冻结本地权重。开发结果未用于选择方法或超参数；全部模型、阈值、配置、特征、输入索引及代码在打开确认分数前锁定。

|方法|固定13类宏F1|准确率|
|---|---:|---:|
|像素特征|48.09%|57.28%|
|像素+HOG|44.88%|54.65%|
|像素+方向边缘|53.29%|59.90%|
|DINO+像素|55.44%|65.16%|

DINO+像素相对像素基线增加7.35个百分点；六家族配对bootstrap探索性95%区间为[2.64,9.91]个百分点，条件于既定模型。该结果不证明其相对方向边缘的显著优势，更不构成方法创新。DINO+像素对position及未受训justify的F1均为0。

## 冻结检测结果

训练正例条件为clean/jpeg95/shift_x1；负例条件为identity/jpeg95/shift_x1/jpeg95_shift_x1。JPEG90/98未参与本轮拟合与阈值校准。阈值取两个开发家族各负例条件95%经验高分位的最大值，使用严格大于号判变更。开发只有6个视图，不能证明总体5%误报上界。

|方法|干净检出率|JPEG95变更检出率|已知条件最差误报率|未见JPEG条件最差误报率|
|---|---:|---:|---:|---:|
|整页残差面积|27.92%|45.11%|6.25%|12.50%|

每个误报条件有16个基准视图、六个家族，6.25%对应1/16个视图。本轮学习方法在JPEG98上误报3/16；干净检出398/419，JPEG95变更检出299/419。圆角干净检出21/33。不能将高JPEG变更检出率忽略同时存在的无改动误报。旧run04模型沿用原阈值，其DiffSpot原始数据没有真实站点ID，故直接迁移只作额外诊断。

本轮学习检测器接DINO+像素分类器后，干净确认样本固定13类宏F1为53.25%（拒绝计错）。干净分类和检测改善未解决压缩下的误报与漏检。

## 归档与复现

`outputs/confirmation_summary.json`保存完整各类/各条件分数及按来源家族的配对区间。`outputs/public_dataset_index.json`与`outputs/public_decisions.json`保留全部逐样本分类和检测决定，可重算确认结果；完整分数、特征、模型和日志留在本地。原始清理/恢复失败尝试留在本地失败目录；修复均发生于本轮模型评分前，见`outputs/generation_revision.json`。

代码入口依次为`code/acquire.py`、`code/render.mjs`、`code/extract.py detector`、`code/extract.py classification`、`code/evaluate.py fit`、`code/evaluate.py confirmation`。渲染依赖Chrome、Playwright和sharp；特征提取依赖NumPy/OpenCV/Pillow/scikit-learn，DINO还需本地Torch/Transformers及冻结权重。源代码下载按`source_specs.json`固定版本核验。完整本地恢复输入与图片不在公开仓库；公开协议删除了机器路径，因此公开导出哈希与本地原始协议哈希应分别核验。Chrome版本和渲染设置记录于审计文件，跨环境重新渲染不保证逐像素相同。

独立复算100个统计单元，33个冻结文件哈希一致，8项Python和5项变更算子测试通过。Word任务书未修改，无外租算力或付费API。

当前完成的是本轮本地受控来源确认。后续若继续，应先取得有真实站点标识、类别覆盖充分的外部截图及压缩无改动对照，并在训练/开发集改进；任何新方法都必须使用新的确认集。此次确认结果保持冻结，不作为后续调参集。
