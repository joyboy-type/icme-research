# 真实版本截图配对：有边界的公开来源核查

本轮已在Mac实际下载并核验两个开源项目的8对版本截图：6对修改候选、2对未修改基准对照。**找到了可追溯的真实开发变化，但尚未形成覆盖13类、来源隔离充分的正式评测集。** 未注入CSS、未训练模型、未选择阈值，旧419及其他已揭盲确认数据保持冻结。

## 已验证的配对

配对依据是同一仓库、同一路径，在实际提交与其第一父提交之间的版本关系；每个原始文件都按Git blob哈希核验。共14份唯一PNG，按内容去重只保存一份；原图和许可证保留本地，不上传公开仓库。

Ionic RTL提交完整文件清单只有SCSS修复和一张PNG，定位依据较清楚；目视核查可见箭头由背离按钮改为指向按钮，同时存在其他位置的低幅像素差异。两对未修改对照像素一致，但它们复用同一版本化基准文件，**不是独立重复截屏，不能估计渲染噪声或检测误报率**。

Ionic特性提交的API文件页达到300条上限。本轮仅选择并逐一核验该页中两个已存在的modified alert/basic Chrome截图，未声称穷尽此提交。TypeScript为真实官网历史快照；Ionic为真实组件项目开发回归快照，均不能直接称为独立生产网站验证。

## 授权、来源分组和标签

Ionic固定版本根目录许可证为MIT；TypeScript官网为CC-BY-4.0。许可证原始字节按Git blob核验，并检查相关前后版本根目录的许可证哈希一致。来源链接、提交、文件路径和许可证信息保留用于归属说明。公开材料只含代码、配置、指纹和筛选后的核查元数据。

所有Ionic组件、提交、浏览器与视口归为同一个项目组，TypeScript官网归为另一个项目组。当前只有2组，不能无泄漏地形成训练、开发、确认三组。此次只是探索性来源核查，没有作正式划分。

此次核查没有产出经过独立人工确认的13类单变化标签：箭头方向变化需决定是否在现有分类范围内；另外两对是多项布局变化；历史官网对还缺匹配的捕获几何。**纯justify和纯position的覆盖均未被证明补齐。** 完整判断见`outputs/annotation_review.json`，标签不能由提交关键词自动生成。

## 其他已核查入口

- **Design2Code**：核对484条HTML编号均有上游原网址映射，按本机离线公共后缀表可解析出466个注册域名组；这不等于466个独立作者或当前活跃网站。其页面是经过处理的真实来源单页，图片已由作者替换为占位图；没有可直接使用的真实版本变化配对。本轮仅保留来源映射/文件树，并查看一份HTML预览，没有生成新CSS探针。
- **WebSRC**：官方说明有网页、截图、站点标识和问答；未验证同页面的版本变化配对，未下载大型压缩包。
- **WebLINX**：公开元数据列出交互演示，未核验到版本变化配对或本任务类别标签。
- **WUICC-bench、DiffSpot**：已核查材料描述受控变更生成，不能替代真实版本变化证据。
- 检查了Ant Design、Primer、FAST、Spectrum、Shoelace、Calcite、GOV.UK等仓库当前文件树，未在所查路径找到直接版本化PNG基准；这不证明它们没有外部截图服务。Excalidraw所见为营销/示例截图，未验证版本配对。WordPress文件树连接两次失败，保留未核实状态。

入口、版本与具体限制见`outputs/source_audit.json`及`outputs/design2code_audit.json`。此次核查有边界，不声称覆盖所有公开数据。

## 后续所需数据条件

公开来源路线可行，但正式实验还需要：更多独立项目或站点；在同页面、同视口、固定浏览器/字体环境下的真实版本前后截图；可追溯提交或部署版本与源码差异；经过复核的单变化/多变化说明；以及同版本独立重复截屏的无变化对照。justify、position必须在各划分中有多来源支持。

若补充自有数据，最小配对记录应包含`project_or_site_id`、`page_or_test_id`、`before_version`、`after_version`、前后PNG、捕获环境、变更依据和可用授权。标签未核实可先留空，不能硬填13类。

当前完成的是来源可用性核查，不是新模型泛化实验。现有2个项目的小批样本和不完整类别标签不足以支撑后续训练/调参/正式确认，因此本轮不据此继续改模型或宣布泛化。

- `outputs/pair_audit.json`：8对原尺寸、像素指纹与变化统计；尺寸不同时不缩放评分。
