# 开发集抗扰动诊断

仅使用历史240对开发截图，派生6种负例和4种正例条件，做三折按原图分组的折外评测。旧155、355对确认截图及72对确认无改动样本均未用于本轮。Word任务书保持v1.1冻结。

本轮评测的是二元改动检测门槛，不是13类分类F1。三种配准与两种固定残差共6个配置在运行前写入protocol.json。阈值仅用其余两折负例校准，取各扰动95百分位阈值的最大值；相同标称5%目标不代表相同实际误报率。

|配置|真实改动检出率|最差单项误报率|
|---|---:|---:|
|global_phase_blur8|25.83%|5.83%|
|global_phase_pixel4|6.67%|5.83%|
|none_blur8|1.67%|7.08%|
|none_pixel4|1.67%|4.58%|
|tile_consensus_blur8|22.50%|5.42%|
|tile_consensus_pixel4|6.25%|5.00%|

整页校正加平滑使clean检出率从1.67%升到25.83%，但最差误报为5.83%；分块一致性加平滑为22.50%和5.42%。这些是开发诊断结果，不能宣称检测器已可用。

两种blur8配置对位置、文字、圆角的clean检出率都为0。分块法在一个已知对角位移负例上接受了错误位移。JPEG后多出的检出包括噪声促成的越阈值，不能解释为语义敏感度提高。所有区间仅条件于当前折和阈值，未覆盖阈值训练变化或多配置选择。

保持扩量和租卡暂停。后续可研究局部残差强度或压缩噪声模型。3个MIT模板家族的固定源码和许可证已核查，依赖、外部素材与足够独立的模板家族仍需准备；未生成新的基准图像。

每种方法的CSV保留全部240原图在10个条件下的折外判定，足以重算检出率与误报率。原图、失败截图、缓存和完整配准日志只保留本地。source_catalog.json给出候选来源和限制。复跑需先恢复清单中的官方图片，再按run.json运行；公开配置已移除本机Word路径，不会编辑Word。
